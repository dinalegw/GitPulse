# GitPulse 🚀

> Keep your GitHub contribution streak alive with automated, configurable commits.

![Version](https://img.shields.io/badge/version-v1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Go](https://img.shields.io/badge/Go-1.26+-00ADD8?logo=go)
![Status](https://img.shields.io/badge/status-In%20Development-orange)

GitPulse is an open-source command-line tool that helps developers automate scheduled Git commits to repositories they choose. It is designed to reduce the repetitive work of making routine commits while giving users complete control over scheduling and configuration.

> **GitPulse is intended for automating commits according to your own workflow. Users are responsible for ensuring automated commits accurately represent meaningful repository activity.**

---

# ✨ Features (v1.0)

* Configure a local Git repository
* Set the desired number of commits per day
* Automatically create commits
* Automatically push commits to GitHub
* Simple configuration
* Cross-platform support (Windows, macOS, and Linux)
* Logging and error handling

GitPulse aims to provide a reliable and configurable automation tool for developers who want to maintain consistent Git activity without repeatedly performing routine Git commands manually.

---

# ⚙️ Planned Workflow

GitPulse will:

1. Read your configuration.
2. Select the configured repository.
3. Generate the configured number of commits.
4. Stage changes.
5. Create commits.
6. Push to the remote repository.
7. Log all activity.
